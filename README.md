## 📌 Project Overview

This project demonstrates a structured manual software testing process for a web-based e-commerce application.

The project covers test planning, test case design, functional testing, negative testing, checkout validation, test execution, defect documentation, and test reporting.

The testing was performed against the **SauceDemo** public demonstration application.

---

## 🎯 Testing Objectives

- Verify core e-commerce functionality
- Validate user authentication
- Test product interaction
- Verify shopping cart functionality
- Validate checkout workflows
- Test required-field validation
- Document test execution results
- Practice professional QA documentation

## 🔍 Key Testing Performed

### Authentication

Verified successful login using the application's demo credentials.

### Product Testing

Verified product listings, product images and product detail navigation.

### Shopping Cart

Verified that products could be added to and removed from the shopping cart.

### Checkout

Verified the checkout workflow using test data.

### Validation

Verified required-field validation for:

- First Name
- Last Name
- Postal Code
