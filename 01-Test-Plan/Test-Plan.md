# E-Commerce Website — Test Plan

## 1. Project Overview

This project demonstrates a manual software testing process for a web-based e-commerce application.

The objective is to verify that users can browse products, search for products, manage their shopping cart, register/login, and complete the checkout process successfully.

## 2. Testing Objectives

- Verify core e-commerce functionality
- Identify functional defects
- Verify input validation
- Test positive and negative scenarios
- Verify user experience across important workflows
- Document and report defects clearly

## 3. Scope

### In Scope

- User registration
- User login
- Product search
- Product browsing
- Product details
- Add to cart
- Update/remove cart items
- Checkout
- Form validation
- Logout

### Out of Scope

- Payment gateway security testing
- Performance/load testing
- Penetration testing
- Backend/database testing

## 4. Testing Types

- Functional Testing
- Smoke Testing
- Regression Testing
- Positive Testing
- Negative Testing
- UI Testing
- Usability Testing

## 5. Test Deliverables

- Test Plan
- Test Scenarios
- Test Cases
- Bug Reports
- Test Execution Results
- Test Summary Report

## 6. Entry Criteria

Testing will begin when:

- Application is accessible
- Required features are available
- Test environment is operational
- Test data is available

## 7. Exit Criteria

Testing will be considered complete when:

- Planned test cases have been executed
- Critical defects have been reported
- Regression testing has been completed
- Test results have been documented

## 8. Defect Severity

| Severity | Description |
|---|---|
| Critical | Prevents a major business function from operating |
| High | Major functionality is significantly affected |
| Medium | Functionality is affected but a workaround exists |
| Low | Minor issue with limited functional impact |

## 9. Expected Outcome

The objective is to identify functional and usability issues and provide clear documentation that can support the development team's defect resolution and release decisions.
